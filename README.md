# Smog Simulator — Exposure Budget & Causal What-If Assistant

Built for **Google PromptWars Virtual — Challenge 6 (Urban Air Quality Assistant)**.

A mobile-first urban air-quality what-if simulator that turns live hourly $\text{PM}_{2.5}$ forecasts into a personal 24-hour exposure curve, paired with a grounded Gemini causal explainer and deterministic fallbacks.

> Repository is currently at **M0 (Foundation)**. See [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md), [docs/ENGINE_SPEC.md](docs/ENGINE_SPEC.md), and [AGENTS.md](AGENTS.md) for the full specification and milestone plan.
